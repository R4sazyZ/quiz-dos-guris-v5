# Quiz Amigos — Criador v5

Fluxo correto:
1. O criador cria o quiz e informa apenas o próprio nome.
2. O site sorteia 50 perguntas sobre o criador.
3. O criador NÃO precisa responder nenhuma pergunta.
4. O criador recebe código + PIN.
5. Os amigos usam o código, colocam seus nomes e respondem tentando adivinhar o criador.
6. O criador abre o painel com o PIN e avalia cada resposta nas 10 categorias.
7. O participante acompanha a pontuação e o ranking.

A versão v5 também remove o Express e usa somente Node.js nativo, reduzindo problemas comuns de deploy no Render.

## Render
- Type: Web Service
- Build Command: deixe vazio ou use `npm install`
- Start Command: `npm start`
